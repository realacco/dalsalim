## 어떻게 쓰나

**파일을 열기 전에 여기서 grep 한다.** 그 파일이 어느 기능을 떠받치는지 먼저 안다.

```bash
grep 'services/book.ts' docs/04-기능-정의서-인덱스.md    # 이 파일을 고치면 흔들리는 기능
grep 'F-ENT-04' docs/04-기능-정의서-인덱스.md            # 이 기능이 사는 코드
grep 'H3' docs/04-기능-정의서-인덱스.md                  # 이 하드룰이 걸린 기능
```

더 파고들 땐 Notion 을 질의한다 (data source `collection://728ff8e5-e6a6-4db1-be61-5e4b84ea0687`):

```sql
SELECT "기능 ID" FROM "collection://728ff8e5-..." WHERE "하드룰" LIKE '%H3 %'
```

- **도메인 5개는 커밋 scope · `server/routes` · `mobile/entities` 와 같은 축이다.**
- **하드룰(H1~H9)은 `CLAUDE.md` 의 「도메인 하드룰」 9개다.** 리뷰의 핵심 축.
- 문서와 코드가 다르면 임의로 맞추지 않는다. 근거를 대고 사용자가 정한다.
