# 작업 열기

**절차는 `.claude/process/start-task.md` 에 있다. 그 파일을 읽고 그대로 따른다.**

여기에 절차를 옮겨 적지 않는다 — 관문 훅(`.claude/hooks/guard-branch.mjs`)의 차단 메시지도
같은 파일을 가리킨다. 두 벌로 두면 갈라지고, 갈라졌을 때 어느 쪽이 맞는지 또 모르게 된다.

## 인자

- `/task F-FAM-05` — 기능 ID. 절차 ① 의 "기능을 정한다"가 이미 끝난 상태로 시작한다
- `/task 참여 요청 승인` — 말로 준 경우. 인덱스에서 후보를 찾아 **사용자에게 확인받고** 시작한다
- `/task` — 현재 브랜치 이름에서 기능 ID 를 읽는다. 없으면 무엇을 할지 묻는다

## 잊지 말 것

- **③ 에서 반드시 멈춘다.** 산정한 태스크 목록을 보여주고 승인을 받은 뒤에 이슈를 만든다.
  에이전트가 뽑은 목록은 초안이지 계획이 아니다
- 명령이 기획서·하드룰과 어긋나면 **이슈를 만들기 전에 멈추고 묻는다**
  (CLAUDE.md 「명령이 문서와 다를 때 — 네 갈래」)
- 기능 정의서를 **전부 읽지 않는다.** 인덱스로 좁힌 뒤 해당 페이지 한둘만 연다
