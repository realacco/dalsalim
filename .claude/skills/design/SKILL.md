# 시안 먼저 보기

**절차는 `.claude/process/start-design.md` 에 있다. 그 파일을 읽고 그대로 따른다.**

여기에 절차를 옮겨 적지 않는다 — `/task` 와 같은 이유다. 두 벌로 두면 갈라진다.

## 인자

- `/design F-ENT-12` — 기능 ID. 절차 ① 의 "무엇을 그릴지"가 이미 정해진 상태로 시작한다
- `/design 카테고리 기억해서 보여주기` — 말로 준 경우. 인덱스에서 후보를 찾아 **확인받고** 시작한다
- `/design` — 무엇을 그릴지 묻는다. 이 절차는 브랜치를 만들기 **전**에 오므로 보통 `main` 에서
  불리고, 브랜치 이름에서 읽을 기능 ID 가 없는 게 정상이다

## 잊지 말 것

- **부르지 않았으면 이 절차는 없는 것이다.** 시안이 매번 필요하지는 않다.
  그리는 게 나아 보이면 **한 줄로 제안하고 그냥 진행한다.** 두 번 묻지 않는다
- **예쁜 정상 화면 한 장만 내면 관문이 아니라 통과의례가 된다.**
  갈림길은 A/B 두 개, 빈 상태·실패·경계 화면은 반드시 같이 그린다 (절차 ③)
- **없는 색과 없는 컴포넌트를 지어내지 않는다.** 모자라면 그게 열린 결정이다 (절차 ②)
- **열린 결정이 하나라도 남아 있으면 `/task` 로 넘어가지 않는다**
